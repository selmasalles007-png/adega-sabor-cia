# Adega Sabor & Cia

## Estrutura
- `index.html`: estrutura da página.
- `css/style.css`: estilos complementares.
- `js/script.js`: funcionalidades JavaScript originais.
- `server.js`: servidor local em Node.js.
- `package.json`: comando para iniciar o servidor.

## Como executar
1. Instale o Node.js.
2. Abra o terminal dentro desta pasta.
3. Execute `npm start`.
4. Acesse `http://localhost:3000` no navegador.

Observação: o visual original usa Tailwind CSS, Font Awesome e Google Fonts por CDN.
É necessário estar conectado à internet para carregar esses recursos externos.
